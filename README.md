# Project — Weather App

A simple weather app made using **HTML, CSS, and JavaScript**.

## What it does

- Shows weather for a city you search
- Can also use your **current location**
- Has **Light/Dark mode**

## How to run

1. Open `index.html` with **Live Server**

## How to use

- Type a city name → click **Search**
- Or click **Use Current Location** → allow permission

## Files

- `index.html` — page structure
- `style.css` — design/style
- `index.js` — weather API + button logic

## API key

The API key is inside `index.js` (`API_KEY`). If it doesn’t work, replace it with your own OpenWeatherMap key.
